> 版本 v1.2 · 2026-11-26。面向**使用者**。每个业务按「**业务目标 → 步骤 → 完成标志**」组织：先看清这个业务为你达成什么，再按步骤一步步做，最后用"完成标志"确认做成了。
> 步骤中标注：【你】= 必须亲手做的（扫码/审内容/点发布）；【助手】= 对 Claude Code 说一句话；【系统】= hub 自动完成。

## 目标 1：把这台电脑装成「能干活的驾驶舱」（每台电脑一次，约 30 分钟）

**业务目标**：你的电脑上跑起一个本地中控（hub），它连着云端素材库、装着 AI 技能、能驱动 ego 浏览器替你操作各平台页面。装完这台电脑就"上岗"了。

**步骤**：

1. 【你】浏览器打开 `http://8.148.26.166:2680/` → 注册（**邮箱或手机号** + 密码 ≥8 位，输两遍）→ 登录进入**素材库**。直接注册会自动创建你的 workspace（你是拥有者）。
2. 【你】安装 Node ≥22.5（`node -v` 验证）和 Python 3。
3. 【你】安装 **ego lite**（Citro Labs 官网安装包）——它是替你操作平台页面的 AI 浏览器，**必须亲手装**，任何助手不得代装。
4. 【你】拉代码并装技能（装完新开 Claude Code 会话即可用对话驱动一切）：
   ```bash
   git clone git@github.com:Siyue-on-my-way/marketing-ops-hub.git ~/marketing-ops-hub   # 没配 SSH key 就用 https://github.com/Siyue-on-my-way/marketing-ops-hub.git；Windows 建议纯英文路径
   mkdir -p ~/.claude/skills
   cp -r ~/marketing-ops-hub/content-hub ~/.claude/skills/content-hub
   ```
5. 【你】配置：
   ```bash
   cd ~/marketing-ops-hub/backend
   cp config/config.example.json config.json
   # 编辑 config.json：cloud.base_url 改为 http://8.148.26.166:2680
   ```
6. 【你】取密钥：门户顶部「**密钥管理**」页 → 复制**默认密钥**（随时可回来点「复制」取回）。
7. 【助手】"执行云入职"，然后把密钥粘给它；它执行 `node src/hub.mjs join <密钥>`。密钥写入本机凭证文件（`backend/data/credentials.json`，仅本机可读），之后不再需要。
8. 【助手/你】启动中控：`cd ~/marketing-ops-hub/backend && node src/hub.mjs serve`。这个终端**保持运行**——它就是驾驶舱（本机大屏 + 自动排期守护）。关机重开后重跑这一条即可，登录态不丢。
9. 【助手】自检：在仓库根跑 `python3 content-hub/scripts/doctor`。

**完成标志**：doctor 输出 `"ready": true`，且 `cloud.whoami` 显示你的租户名。哪项缺，按 `actions[]` 提示补；装不齐把整段 JSON 发管理员。

**给另一台电脑用**：在门户「密钥管理」新建一把密钥（如"笔记本"），那台电脑重复本章即可。默认密钥**不可吊销**；新建的密钥可随时吊销——怀疑泄露就新建换用、吊销旧的。

## 目标 2：让系统接管你的一个平台账号（每账号一次，10 分钟）

**业务目标**：系统获得该账号的操作位（独立的 ego 浏览器空间 + 登录态），从此可以替它填表、互动、收数据。一个账号只绑一台电脑。

**业务规则**：每平台 ≤5 个号；扫码永远【你】亲手做，系统不碰平台密码；新号自动进入 14 天冷启动（不发布、互动减半），已有老号录入时声明 `--mature` 跳过。

**步骤**：

1. 【助手】"录入我的B站账号，昵称 XXX，是老号" → 它执行：
   ```bash
   node src/hub.mjs accounts add bili "你的B站昵称" --mature   # 新号去掉 --mature（14 天冷启动）
   ```
2. 【助手】"登录这个账号" → 它执行 `node src/hub.mjs accounts login <account_id>`，弹出浏览器。
3. 【你】手机打开对应平台 App 扫码；系统自动快照核对昵称（不符会立即停下——通常是把录入昵称写错了）。
4. 【助手】同时告诉它发布模式：默认 **review**（系统填好表单、你亲手点发布）；想要全自动就说"开启自动发布"（= `accounts set <id> --auto-publish on`，关掉用 `off`）。**两种模式内容都必须先经你过目**，区别只在最后一下谁来点。

**完成标志**：`node src/hub.mjs accounts list` 里该账号 `login.ok = true`。

**换电脑**：新电脑重新录入 + 扫码，旧电脑不再操作该账号。

## 目标 3：把素材放进云端素材库（发帖的前置）

**业务目标**：视频/图片/文案进入 workspace 共享素材库（同事也可见），打上平台标签供"发一条"选用。素材生产仍在你自己的流程完成，系统只管存和发。

**步骤**（三选一，最常用是第 1 种）：

1. 【你】门户网页直接传：登录门户 →「素材库」页 → 上方**上传素材**面板 → 点选/拖入文件（可多选）→ 勾选平台标签 → 「开始上传」。上传后随时在同一页**查看预览、编辑标题/标签/备注、下载、删除、释放占用**。
2. 【助手】把文件给 Claude Code，说"**上传到素材库**，全平台可用"。
3. 【你】手动调 API：
  ```bash
  curl -X POST http://8.148.26.166:2680/v1/materials \
    -H "Authorization: Bearer <你的密钥>" \
    -F file=@video.mp4 \
    -F 'meta={"title":"双十一开箱","type":"video","platform_tags":["common"]}'
  ```

**规则**：`type` ∈ `video|image|text`（网页上传可不填，按扩展名自动识别）；`platform_tags` ⊆ `common,xhs,douyin,tiktok,yt,bili,x,xianyu`（`common` = 全平台可发，只发某平台就写那个代号）；相同文件自动去重（sha256）；单文件 ≤500MB。

**完成标志**：门户「素材库」页能看到这条素材（标题/类型/标签/大小），可查看、下载；同事上传的同 workspace 素材也互相可见。上传/查看/管理在网页上即可闭环，CLI/API 两条路与网页等价。

## 目标 4：把一条素材发到多个平台（核心业务）

**业务目标**：一条素材以各平台适配过的文案（标题/正文/标签逐平台改写）发布出去，URL 归档，第 1/3/7 天自动收数据。

**前提**：目标账号已完成目标 2（`login.ok`），且不在冷启动期（冷启动号不能发）。

**步骤**：

1. 【助手】说"**发一条**"（可加要求："这个视频投小红书和B站，用我的老号，今晚 8 点发"）。系统自动：拉素材候选 → 按平台改写文案 → 出**差异表**给你 → 排期。
2. 【你】**过目差异表并确认**——这是内容人审，不能跳过；不满意让它改。
3. 【系统】到点自动上传素材、填标题/正文/标签，全程拟人节奏，填完截图。
4. 二选一：
   - **review 账号**：【你】打开平台页面**亲手点「发布」**，然后在本机大屏 `http://127.0.0.1:8787` →「待审队列」点「**已发布，回读确认**」；系统回读平台后台核实 URL/状态。
   - **auto 账号**：什么都不用做，系统自动点发布并回读（截图/URL 全程归档审计）。
5. 【系统】回写云端台账；发布后第 1/3/7 天自动采集数据（供目标 8 复盘）。

**完成标志**：大屏上该帖状态变 `confirmed`，带发布 URL；平台后台能看到这条内容。回读未通过 = 平台审核中，稍后在大屏再点一次「已发布，回读确认」即可。

## 目标 5：养号——点赞/评论/话题互动

**业务目标**：账号保持真实活跃（像人在互动，不是机器刷量），trust_score 随无风控天数上涨、配额逐步放开。

**业务规则**：一切互动必须 **AI 草拟 → 你 approve → 才执行**；评论必须引用对方内容，禁止模板群发；执行间隔 30–120 秒随机；活跃时段 9–21 点。

**步骤**：

1. 【助手】说"**养号巡检**"（或"话题互动"并给出话题）。系统按当日剩余配额生成互动计划：读目标帖/话题页 → AI 逐条草拟评论/点赞清单。
2. 【你】在本机大屏 `http://127.0.0.1:8787` →「待审队列」→「互动待审」逐条看草拟内容，点 **approve**（批准执行）或 **reject**（拒绝）；确认都过目了也可"批准今日全部"。
3. 【系统】已批准的互动按拟人间隔自动执行并截图归档。

**完成标志**：大屏「审计时间线」出现 `executed` 记录；「账号健康」里 trust_score 上涨、今日配额用量增加。

## 目标 6：给好友发个性化私聊

**业务目标**：用你的账号给好友发出像人写的私聊（维持关系活人感），不是群发。

**业务规则**：每会话上限 1 条；必须个性化草拟（AI 会结合对方情况写）；你 approve 后才发送。

**步骤**：与目标 5 完全同流程——说"**私聊好友**"（说明对象和意图）→ 【你】大屏 approve → 【系统】发送并截图归档。

**完成标志**：审计时间线出现该私聊的 `executed` 记录 + 截图。

## 目标 7：知道账号今天能不能用（健康检查）

**业务目标**：一眼看清每个账号的可用性：登录态、今日还剩多少配额、trust_score 多少、有没有风控事件。

**步骤**：【助手】说"**看账号健康**"（它跑 `hub health`）；或自己开本机大屏 `http://127.0.0.1:8787` →「账号健康」。

**怎么读**：

- 配额上限（trust=1 时）：发 ≤2 / 赞 ≤30 / 评 ≤5 / 私信 ≤10，每天；**实际余量 = 上限 × trust_score**；
- 新号冷启动：再减半且**不能发**；连续无风控每天 +0.05，满 0.8 且满 14 天自动转正；
- 风控命中：当日清零停机；累计 3 次进 `banned_watch`（全部归零，需人工处理）。

**完成标志**：拿到了"今天哪些号能发、哪些只能互动、哪些停机"的结论，直接用于决定目标 4/5/6 用哪些号。

## 目标 8：复盘——已发帖子效果如何

**业务目标**：知道每条帖子发出去后的表现，以及**和你自己上期同龄帖**（发布后同一天）相比是进步还是退步，指导下期选题和文案。

**步骤**：【系统】发布后第 1/3/7 天自动进各平台创作者后台采集数据（views/likes/comments/shares/涨粉），无需你操作；【助手】到时说"**复盘 <post_id>**"（post_id 在大屏待审队列/审计里）。

**完成标志**：拿到复盘卡片——各天数据 + 与同龄帖均值的差值；让助手解读并给下期建议即可（它还会据此产出"进化提案"，你在大屏 approve 后才生效）。

## 目标 9：让同事和你共用团队空间

**业务目标**：多人多台电脑共用一个 workspace：共享素材库、共享台账；账号不重叠（一个账号只在一台电脑）。

**步骤**：

1. 【你】门户顶部「**邀请**」页 → 生成邀请链接 → 发给同事。
2. 【同事】打开链接注册（自动加入你的 workspace，成为成员，自带一把自己的密钥）。
3. 【同事】在其电脑上按目标 1 装环境、用**自己的**默认密钥 join；再按目标 2 接入**不与你重叠**的账号。

**完成标志**：门户「成员」页能看到同事；两人上传的素材在「素材库」互相可见。拥有者可在「成员」页移除成员（其密钥立即失效）。

## 附录：排障（现象 → 处理）

| 现象 | 处理 |
| --- | --- |
| doctor 某项红 | 按 `actions[]` 提示补；不行把整段 JSON 发管理员 |
| `skipped(no_login)` | 登录态失效：重新做目标 2 的扫码登录 |
| `skipped(quota)` | 当日配额用完，明天再试或换号（先做目标 7 看余量） |
| 风控停机 | 看大屏审计里的截图，次日自动恢复；连续 3 次进 `banned_watch` 需人工 |
| `duplicate` | 同素材同账号同平台防重命中，换素材 |
| 素材一直显示"被占用" | 占用锁 30 分钟自动释放；急用就在门户「素材库」打开该素材点「**释放占用**」 |
| 回读未通过 | 平台审核中，稍后在大屏再点一次「已发布，回读确认」 |
| 云 401 | 凭证被吊销/过期：门户「密钥管理」拿新 key，重新 join |
| 大屏空白/要 token | 本机大屏随 `hub serve` 启动；带 SERVER_TOKEN 的入口是运营大屏（管理员用） |

**纪律（系统强制）**：发布内容永远先经你过目；互动 approve 后才执行；新号 14 天冷启动；验证码/风控即停绝不绕过；只管自有/公司账号（每平台 ≤5），批量注册、模拟人设、群控会被拒绝。

**路线提示**：未支持的场景到父 issue 提需求；疑似 bug 附上 `doctor` 的 JSON 输出。
