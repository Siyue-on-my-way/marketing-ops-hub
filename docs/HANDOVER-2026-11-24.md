# 1. 一句话目标

在已运行的 Maitian-Hub（7 平台自有账号矩阵运营系统）上实现**密码+密钥混合访问体系**：Web 素材台用密码登录（人看，只读浏览租户素材），CLI/hub 用设备密钥（agent 读写），多租户数据隔离、按人粒度吊销——替换现在「服务器 .env 里一把共享 workspace_key」的粗糙鉴权。完整规格在 `docs/ACCESS-SPEC-v1.md`（v1.1），本文档不重复其内容，只补环境、现状与坑。

# 2. 背景与前因后果

## 2.1 项目是什么

自媒体运营者管理**自有账号**（小红书/抖音/TikTok/YouTube/Bilibili/闲鱼/X，每平台 ≤5 个）：素材发布、互动养号、私聊、数据复盘。三层结构：

- **Harness 层**（唯一的 LLM agent）：用户本机 Claude Code/Codex/WorkBuddy 装载 `content-hub/` skill 包——编排、文案改写、互动目标选择。
- **hub 执行层**（`backend/src/`，Node ≥22.5 零第三方依赖）：确定性程序，零 LLM——排期、SQLite 状态机、防重、配额、风控即停、审计、大屏(:8787)。
- **ego lite**：用户本机 AI 浏览器（GUI，不可容器化），适配器执行页面操作；**全部选择器来自知识包 JSON**（`content-hub/docs/knowledge/<platform>.json`），代码写死 hash 类名视为 bug。

完整原始需求：本 issue 描述里的「实施规格书 v1.1」（自包含，可读）。

# 4. 方案与关键决策（与你的任务直接相关的）

| 决策 | 选择 | 理由 | 被否的替代 |
| --- | --- | --- | --- |
| 鉴权模型 | 混合：Web 密码（只读）+ CLI 设备密钥（读写） | 人和 agent 凭证通道分离；密码泄露半径=只读浏览 | 完整用户系统（密码/JWT/找回）——运维负担与 agent 驱动形态不符，已否决；纯密钥（v1.0）——非技术成员没有查看入口，用户否决 |
| 密码哈希 | node:crypto `scrypt(salt,16384)` + `timingSafeEqual` | 零依赖、抗时序 | bcrypt/argon2（第三方依赖，违反零依赖） |
| 会话 | HMAC 签名 cookie（无状态，7 天）+ 内存黑名单 logout | 无会话表；重启清黑名单可接受（只读面） | JWT 库/服务端 session 表 |
| 设备密钥分发 | 邀请码单次兑换 `hub join` | 加人不碰服务器 | 继续共享 env key（痛点本身） |
| 租户隔离 | materials/journals 加 tenant_id，全部查询按 key 的租户过滤 | 一套部署多团队 | 多实例部署（浪费） |
| 兼容 | 旧 MAITIAN_WORKSPACE_KEY 首启自动映射 default 租户 admin key | 现有 hub/部署零破坏 | 强制迁移（破坏性） |
| 限流/防枚举 | redeem 与 /web/login 同 IP 限流 + 统一错误 | 防爆破与枚举 | 验证码（引入外部依赖） |

# 9. 坑与禁忌

- **smoke 基线 114 不得减少**；测试自起 cloud server 用**随机端口**（`20000+pid%20000`）——曾因固定端口撞上残留进程导致假失败；测试崩溃会留孤儿进程，重启前可用 `ss -tlnp` 查。
- `test/redline-check.sh` 会扫描「click 与 发布/提交/publish/submit 同行」——你在别处写发布点击会挂检查；自动发布点击只许在 `backend/src/adapters/submit.mjs`（须保留 AUTO_PUBLISH 字样）。
- SQLite 加列用 `db.mjs:66` 的 PRAGMA table_info 检查 + ALTER 模式（CREATE TABLE IF NOT EXISTS 不会给旧库加列）。
- SQLite UNIQUE 冲突的错误信息含 'UNIQUE'——防重判断靠 `String(e).includes('UNIQUE')`（planner 多处如此），别改成 error code 判断（node:sqlite 抛的是 Error 不是 SQLException 子类）。
- Windows PowerShell 5.1 把 stderr 报成 NativeCommandError——判定以 stdout 的 `@@RESULT@@` JSON + 退出码为准（`backend/src/ego.mjs` 已处理）。
- 适配器页面操作必须走 `backend/src/adapters/runtime.mjs` 的 clickText/clickSelector（坑位 2：滚动→重取坐标→点击，强制封装），不得裸 mouse.click。
- 知识包与策略库都在 `content-hub/docs/`，hub 容器内通过 additional_contexts COPY 到 `/app/knowledge`、`cfg.paths.strategies` 指向容器路径——改路径解析要看 `backend/src/config.mjs` 的三级回退（env → 仓库根 → ROOT 内）。
- ESM 仓库：禁止 `require()`（曾两次误用已修）；大文件写入/读盘用 node:fs 同步 API 保持风格一致。
- 提交署名：沿用仓库现有 git identity（siyue / dukehxin8009@163.com），commit 末尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
